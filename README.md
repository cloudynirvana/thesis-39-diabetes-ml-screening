# Thesis 39: Type 2 Diabetes Screening

**Repository:** `thesis-39-diabetes-ml-screening`
**Author:** Kelechi Emeka Ogbonna
**Status:** Completed (September 2026)
**Keywords:** Type 2 Diabetes Mellitus, Machine Learning, Sub-Saharan Africa, Routine Blood Panel, Predictive Modeling

## Overview
This repository contains the computational framework and manuscript for Thesis #39, exploring the efficacy of machine learning models in screening for Type 2 Diabetes Mellitus (T2DM) using routine, low-cost blood panel data in Sub-Saharan African populations. 

## Connection to the Series
This work is part of Project Confluence, an ongoing series of computational research theses. It builds upon foundational methodologies established in Thesis Zero and leverages feature identifiability techniques developed in Thesis #09.

## Contents
* `THESIS.md`: The complete manuscript in the Nile University 5-chapter format.
* `src/`: Python source code for data preprocessing, model training, and evaluation (Logistic Regression, Random Forest, XGBoost).

## Disclaimer
This project is for computational research purposes only. The models and screening tools developed herein are not intended for clinical diagnostic use.
